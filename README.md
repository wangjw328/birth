# 月光来信

可配置的互动生日网页初版。静态文件位于 dist，可用任意静态服务器运行。

包含：赴约、阅读来信、长按或轻点许愿、生日结尾、重播、环境和弦、文字编辑、两种色调、微光开关、本机草稿、带配置的分享链接。

这是氛围与交互原型：背景为生成图片，镜头通过分层缩放过渡，粒子使用 Canvas。不是可自由旋转的 3D 场景。链接配置存于 URL fragment，不包含云端账号、独立作品数据库或公开访问授权；私人部署的收件人仍需相应访问权限。

音效由 Web Audio 合成，不使用第三方歌曲。所有用户文本通过 textContent 渲染。减少动态效果的系统设置会停用粒子和镜头过渡。

验收：检查 JavaScript 语法、配置编码与解码、所有静态资源路径，以及 HTTP 入口响应。未执行浏览器 UI 自动化测试。

## 部署

GitHub 默认分支使用 `main`。Cloudflare Pages 不需要构建命令，输出目录填写 `dist`。完整设置见 [CLOUDFLARE-DEPLOY.md](CLOUDFLARE-DEPLOY.md)。

线上根地址会自动进入当前最新版生日房间 `/birthday/`；其他主题可从 `/collection/` 查看。
